# Bridge the Growth — Website Project

Official web presence for **Bridge the Growth** digital marketing and business consulting agency.

Tagline: *"See further, grow faster."*

## Folder Structure
- `index.html` : Main HTML website file
- `css/style.css` : Central styling sheet
- `js/script.js` : Mobile navigation & interactive scripts
- `assets/logo/` : Place `B2G.jpeg` here

## How to Edit Logo
Replace your logo image in `B2G.jpeg` .
